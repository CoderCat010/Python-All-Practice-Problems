# Phase 3 — All Practice Tasks


## Task 1 — মুদির তালিকা (ছোট)

**পরিস্থিতি:** রহিমা প্রতি সপ্তাহে মুদির দোকানে যাওয়ার আগে একটা তালিকা বানান। সমস্যা হলো, তিনি অনেক সময় একই জিনিস দুইবার লিখে ফেলেন, আর দোকানে গিয়ে দেখেন তালিকা এলোমেলো, কয়টা জিনিস কেনার আছে তাও গুনে বলতে পারেন না। তাই তিনি চান কম্পিউটার তালিকাটা গুছিয়ে রাখুক।

**তোমার কাজ:** একটা একটা করে জিনিসের নাম input নাও, যতক্ষণ না "শেষ" লেখা হয়। জিনিসটা আগে থেকে তালিকায় থাকলে জানিয়ে দাও, না থাকলে যোগ করো। শেষে মোট কয়টা আলাদা জিনিস হলো আর ক্রমিক নম্বর দিয়ে পুরো তালিকা দেখাও।

**Given Input:**

```
চাল
ডাল
চাল
তেল
শেষ
```

**Expected Output:**

```
চাল যোগ হলো
ডাল যোগ হলো
চাল আগেই আছে
তেল যোগ হলো
মোট আইটেম: 3
1. চাল
2. ডাল
3. তেল
```

**Constraint:** ক্রমিক নম্বর (1, 2, 3...) ছাপানোর জন্য আলাদা কোনো গণনার variable বানানো যাবে না। কেউ "চাল " (শেষে ফাঁকা) লিখলেও সেটা "চাল"-এর মতোই ধরতে হবে।

## Task 4 — বাসের ভাড়া

**পরিস্থিতি:** একটা রুটে বাস সব সময় একই ক্রমে পাঁচটা স্টপেজ ছোঁয়: মহাখালী, ফার্মগেট, শাহবাগ, মতিঝিল, সায়েদাবাদ। এই তালিকা কখনো বদলায় না। ভাড়া স্টপেজ গুনে হিসাব হয়, প্রতি স্টপেজে ১০ টাকা। কন্ডাক্টর প্রতিবার হিসাব করতে গিয়ে ভুল করেন, আর যাত্রী উল্টো দিকেও যেতে পারে।

**তোমার কাজ:** যাত্রী কোন স্টপেজে উঠেছে আর কোথায় নামবে, দুটো input নাও। মাঝে কয় স্টপেজের দূরত্ব আর ভাড়া কত দেখাও। কোনো নাম তালিকায় না থাকলে সেটা জানাও। একই স্টপেজ দুবার দিলে আলাদা বার্তা দেখাও।

**Given Input:** (উদাহরণ ১, ২, ৩ ও ৪, মাঝে ফাঁকা লাইন)

```
ফার্মগেট
মতিঝিল

সায়েদাবাদ
মহাখালী

শাহবাগ
বনানী

শাহবাগ
শাহবাগ
```

**Expected Output:** (উদাহরণ ১, ২, ৩ ও ৪ — একই ক্রমে)

```
ফার্মগেট থেকে মতিঝিল: 2 স্টপেজ, ভাড়া 20 টাকা

সায়েদাবাদ থেকে মহাখালী: 4 স্টপেজ, ভাড়া 40 টাকা

অজানা স্টপেজ: বনানী

একই স্টপেজে উঠা-নামা সম্ভব নয়
```

**Constraint:** প্রতি স্টপেজের ভাড়া (১০) আর প্রতিটা স্টপেজের নাম পুরো কোডে একবারের বেশি লেখা যাবে না।

## Task 5 — দুই ক্লাবের সদস্য

**পরিস্থিতি:** কলেজে ক্রিকেট ক্লাব আর ফুটবল ক্লাব আছে। ক্রীড়া শিক্ষক বছরের শেষে ক্লাবদুটোর সদস্যদের নিয়ে একটা হিসাব চান। রেজিস্ট্রেশনের সময় তাড়াহুড়োয় কারো নাম একই ক্লাবের খাতায় দুবার উঠে যায়, কাজেই সংখ্যা গোনার সময় সেই বাড়তি নামটা ধরা চলবে না।

**তোমার কাজ:** প্রথমে ক্রিকেট ক্লাবের সদস্যদের নাম একে একে input নাও ("শেষ" লিখলে বন্ধ), তারপর ফুটবল ক্লাবের। প্রতিটা ক্লাবে আলাদা সদস্য কতজন, কারা দুই ক্লাবেই আছে, কারা শুধু ক্রিকেটে, কারা শুধু ফুটবলে, আর দুই ক্লাব মিলিয়ে মোট কতজন আলাদা সদস্য সেটা দেখাও। নামের তালিকাগুলো বর্ণানুক্রমে সাজানো থাকবে।

**Given Input:**

```
রাহি
সুমি
তানভীর
রাহি
নাবিল
শেষ
সুমি
নাবিল
ফারহান
মিতা
শেষ
```

**Expected Output:**

```
ক্রিকেট ক্লাবের আলাদা সদস্য: 4 জন
ফুটবল ক্লাবের আলাদা সদস্য: 4 জন
দুই ক্লাবেই আছে: নাবিল, সুমি
শুধু ক্রিকেটে: তানভীর, রাহি
শুধু ফুটবলে: ফারহান, মিতা
মোট আলাদা সদস্য: 6
```

**Constraint:** কোনো নাম কোডে হাতে লেখা যাবে না। এমন একটা ইনপুট দিয়েও চালিয়ে দেখো যেখানে দুই ক্লাবে একজনও মিলছে না, আর এমন একটা যেখানে সবাই মিলছে।

## Task 6 — দোকানের স্টক (ঠিক ৩টা সমস্যা) (মাঝারি)

**পরিস্থিতি:** একটা চায়ের দোকানে চা ১০টা, কফি ৫টা আর বিস্কুট ৮টা আছে। কিছু বিক্রি হলে দোকানদার কী বিক্রি হলো আর কতটা, সেটা বলেন। নিয়ম: জিনিসটা দোকানে না থাকলে "এই পণ্য নেই" দেখাবে আর স্টকে কিছু যোগ হবে না। পরিমাণ ০ বা ঋণাত্মক হলে "অবৈধ পরিমাণ"। যা আছে তার চেয়ে বেশি চাইলে "মজুদ কম, আছে ..." দেখাবে। না হলে বিক্রি হবে আর কত বাকি থাকল দেখাবে। বাকি ০ হয়ে গেলে জিনিসটা তালিকা থেকেই মুছে যাবে। কোডটা লেখা হয়েছে, কিন্তু ঠিকমতো চলছে না। এতে ঠিক ৩টা সমস্যা আছে।

```python
stock = {"চা": 10, "কফি": 5, "বিস্কুট": 8}
item = input("কী বিক্রি হলো: ").strip()
qty = int(input("কতটা: "))
if item in stock:
    if qty <= 0:
        print("অবৈধ পরিমাণ")
    elif qty > stock[item]:
        print("মজুদ কম, আছে", stock[item])
    else:
        stock[item] - qty
        print("বিক্রি সম্পন্ন। বাকি:", stock[item])
        if stock[item] = 0:
            del stock[item]
            print("মজুদ শেষ, তালিকা থেকে সরানো হলো")
else:
    stock[item] = qty
    print("এই পণ্য নেই")
```

**তোমার কাজ:** ৩টা সমস্যা খুঁজে ঠিক করো।

**Given Input:** (পাঁচটা আলাদা চালানো, প্রতিবার প্রোগ্রাম নতুন করে শুরু, মাঝে ফাঁকা লাইন)

```
চা
4

কফি
5

বিস্কুট
9

পানি
2

চা
0
```

**Expected Output:** (একই ক্রমে)

```
বিক্রি সম্পন্ন। বাকি: 6

বিক্রি সম্পন্ন। বাকি: 0
মজুদ শেষ, তালিকা থেকে সরানো হলো

মজুদ কম, আছে 8

এই পণ্য নেই

অবৈধ পরিমাণ
```

**Constraint:** ঠিক করার পর প্রতিটা বদলানো লাইনের পাশে এক লাইনের comment-এ লিখে রাখবে কেন ঠিক করলে।

## Task 7 — সিনেমা হলের সিট বুকিং (মাঝারি)

**পরিস্থিতি:** একটা ছোট সিনেমা হলে ৩টা সারি, প্রতি সারিতে ৪টা সিট। সারি আর সিট দুটোই ১ থেকে গোনা হয়। এখন বুকিং হয় খাতায় হাতে, তাই মাঝে মাঝে একই সিট দুইজনকে দেওয়া হয়ে যায়। হল-মালিক চান প্রতিবার বুকিংয়ের পর সিটের নকশা দেখা যাক: খালি সিট O, বুক হওয়া সিট X।

**তোমার কাজ:** বুকিং input নাও: প্রথমে সারি নম্বর, তারপর সিট নম্বর। সারি নম্বরের জায়গায় "শেষ" লিখলে বুকিং বন্ধ। সফল বুকিং হলে বার্তা আর নকশা দেখাও। সিট আগেই বুক থাকলে বা নম্বর হলের মধ্যে না পড়লে আলাদা বার্তা দেখাও (এই দুই ক্ষেত্রে নকশা দেখাতে হবে না)। শেষে কয়টা সিট এখনো খালি আছে দেখাও।

**Given Input:**

```
1
2
1
2
3
4
5
1
শেষ
```

**Expected Output:**

```
সিট বুক হলো
O X O O
O O O O
O O O O
সিট আগেই বুক করা
সিট বুক হলো
O X O O
O O O O
O O O X
সারি বা সিট নম্বর ঠিক নেই
বাকি খালি সিট: 10
```

**Constraint:** সারির সংখ্যা (3) আর কলামের সংখ্যা (4) পুরো কোডে একবারই লেখা যাবে। ১২টা O হাতে লেখা যাবে না। একটা সারির সিট বুক করলে যেন অন্য কোনো সারিতে কিছু বদলে না যায়, এটা নিজে পরীক্ষা করো। সারি বা সিট নম্বর ০ আর ঋণাত্মক (যেমন -1) দিয়েও চালিয়ে দেখো।

## Task 9 — নম্বর খোঁজার প্রোগ্রাম (ঠিক ৩টা সমস্যা)

**পরিস্থিতি:** একজন শিক্ষক এমন একটা প্রোগ্রাম চান যেটায় ছাত্রের নাম দিলে নম্বর দেখা যাবে। নাম খাতায় না থাকলে সেই ছাত্রের নম্বর সাথে সাথে যোগ করে নেওয়া যাবে। সবশেষে ক্লাসের সর্বোচ্চ নম্বরধারী ছাত্র কে, সেটাও দেখাবে। তিনি কোড লিখেছেন, কিন্তু কোডে ঠিক ৩টা সমস্যা আছে।

```python
scores = ["রাহি": 78, "সুমি": 45, "তানভীর": 30]
name = input("নাম: ")
if name in scores:
    print(name, "→", scores[name])
else:
    scores[name] = int(input("নতুন নম্বর: ")
    print("যোগ হলো")
best_name = ""
best_marks = 0
for n in scores:
    if scores[n] > best_marks:
        best_name = n
        best_marks = n
print("সর্বোচ্চ:", best_name, best_marks)
```

**তোমার কাজ:** ৩টা সমস্যা খুঁজে ঠিক করো।

**Given Input:** (উদাহরণ ১ ও ২, মাঝে ফাঁকা লাইন, প্রতিটা উদাহরণ আলাদা বার চালাবে)

```
সুমি

নাবিল
88
```

**Expected Output:** (উদাহরণ ১ ও ২ — একই ক্রমে)

```
সুমি → 45
সর্বোচ্চ: রাহি 78

যোগ হলো
সর্বোচ্চ: নাবিল 88
```

**Constraint:** ঠিক করার পর প্রতিটা বদলানো লাইনের পাশে এক লাইনের comment-এ লিখে রাখবে কেন ঠিক করলে।

## Task 11 — রাইডারের দিনের লগ (মাঝারি)

**পরিস্থিতি:** একজন ডেলিভারি রাইডার সারা দিন বিভিন্ন জায়গায় থামে। প্রতিটা থামার সময় সে জায়গার নাম আর কত মিনিট থেমেছে লিখে রাখে। দিন শেষে ম্যানেজার জানতে চান প্রথম আর শেষ স্টপ কোনটা, কোন কোন জায়গায় রাইডার একাধিকবার গিয়েছে (কতবার আর মোট কত মিনিট), আর কোন জায়গায় মোট সবচেয়ে বেশি সময় কেটেছে।

**তোমার কাজ:** প্রথমে কয়টা স্টপের তথ্য আছে তা input নাও, তারপর প্রতিটা স্টপের জন্য জায়গার নাম আর মিনিট input নাও। নিচের ফরম্যাটে ফল দেখাও।

**Given Input:**

```
6
Mirpur
15
Farmgate
10
Mirpur
20
Shahbag
5
Farmgate
25
Mirpur
5
```

**Expected Output:**

```
প্রথম স্টপ: Mirpur
শেষ স্টপ: Mirpur
একাধিকবার গিয়েছে:
Mirpur - 3 বার, মোট 40 মিনিট
Farmgate - 2 বার, মোট 35 মিনিট
```

## Task 31 — উপস্থিতির হিসাব (ঠিক ৩টা সমস্যা) (মাঝারি)

**পরিস্থিতি:** একটা ক্লাসে চারজন ছাত্র আছে: Rahim, Karim, Nadia, Sara। শিক্ষক প্রতিদিন যারা উপস্থিত ছিল তাদের নাম বলেন। প্রতিদিন শেষে প্রোগ্রাম দেখাবে সেদিন কে অনুপস্থিত ছিল (বর্ণানুক্রমে)। সব দিন শেষে দেখাবে কে প্রতিদিনই উপস্থিত ছিল, যে ছাত্র একদিনও অনুপস্থিত হয়নি তাকে পুরস্কার দেওয়া হবে। কোডটা লেখা হয়েছে, কিন্তু ঠিকমতো চলছে না। এতে ঠিক ৩টা সমস্যা আছে।

```python
roster = {"Rahim", "Karim", "Nadia", "Sara"}
always = set(roster)
days = int(input("কত দিন: "))
day = 1
while day <= days
    present = {}
    name = input("নাম: ")
    while name != "শেষ":
        present.add(name)
        name = input("নাম: ")
    always = always & present
    print("দিন", day, "অনুপস্থিত:", sorted(roster - present))
print("প্রতিদিন এসেছে:", sorted(always))
```

**তোমার কাজ:** ৩টা সমস্যা খুঁজে ঠিক করো।

**Given Input:**

```
3
Rahim
Karim
Nadia
Sara
শেষ
Rahim
Nadia
Sara
শেষ
Rahim
Sara
শেষ
```

**Expected Output:**

```
দিন 1 অনুপস্থিত: []
দিন 2 অনুপস্থিত: ['Karim']
দিন 3 অনুপস্থিত: ['Karim', 'Nadia']
প্রতিদিন এসেছে: ['Rahim', 'Sara']
```

**Constraint:** ঠিক করার পর প্রতিটা বদলানো লাইনের পাশে এক লাইনের comment-এ লিখে রাখবে কেন ঠিক করলে।
