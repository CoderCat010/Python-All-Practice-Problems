# Phase 1 – Practice Tasks (Round 1)

নিয়ম: প্রতিটা task নিজে করবে। কোনো hint বা সমাধান দেওয়া নেই। কোড লেখা শেষে আমাকে পাঠাও, আমি দেখাব ভুল কোথায়, আর প্রতিটা ভুলের জন্য দুটো বিকল্প উপায় বলব। যেখানে "ভবিষ্যদ্বাণী" বা "অনুমান" লিখতে বলা আছে, সেখানে চালানোর **আগে** লিখবে।

## Task 1 – ছোট: ২৫ আর ৪ মিলে ২৫৪

**পরিস্থিতি:** মিনা আপার একটা ছোট দোকান আছে। দুটো জিনিসের দাম যোগ করার জন্য তিনি নিজে একটা প্রোগ্রাম লিখেছেন। কিন্তু ২৫ আর ৪ দিলে তাঁর প্রোগ্রাম বলছে মোট ২৫৪ টাকা। দোকানে এই হিসাব নিয়ে ক্রেতার সাথে রোজ ঝামেলা হচ্ছে।

তাঁর কোড:

```
a = input()
b = input()
print(a + b)
```

**তোমার কাজ:** কেন এমন হচ্ছে তা খুঁজে বের করো, আর প্রোগ্রামটা ঠিক করো যাতে সংখ্যার যোগফল আসে। দশমিক দামও (যেমন 2.5) যেন চলে।

**Given Input:**

```
25
4
```

**Expected Output:**

```
29
```

**Constraint:** `input()` লেখা দুটো লাইনে কোনো পরিবর্তন করা যাবে না।

## Task 2 – ছোট: একই জিনিসের দুই নাম

**পরিস্থিতি:** একটা ছোট স্কুলে রোল নম্বর রাখা হয় একটা খাতায়। শিক্ষক এক ছাত্রের নম্বরটা আরেকজনের নামের পাশে টুকে রাখলেন, তারপর প্রথমজনের নম্বর বদলালেন। তিনি অবাক হয়ে দেখলেন, দ্বিতীয়জনের নম্বর বদলায়নি। Python-এও এমন কিছু ঘটে কি না তিনি জানতে চান।

**তোমার কাজ:** এমন একটা প্রোগ্রাম লেখো যেখানে একটা variable-কে আরেকটা variable-এ দেওয়ার পর প্রথমটা বদলানো হয়। `id()` ব্যবহার করে তিনটা সময়ে দুটো নামের পরিচয় দেখাও: বদলানোর আগে, বদলানোর ঠিক পরে, আর শেষে। একই কাজ একবার সংখ্যা দিয়ে আর একবার string দিয়ে করো। যা দেখলে তা নিজের ভাষায় ব্যাখ্যা করো।

**Constraint:** ব্যাখ্যায় "বাক্স" শব্দটা ব্যবহার করা যাবে না।

## Task 3 – ছোট: error পড়তে শেখা

**পরিস্থিতি:** রাহাত একটা প্রোগ্রামে জিনিসের দাম দ্বিগুণ করতে চেয়েছিল। চালানোর পর লাল রঙে একগাদা লেখা এল আর সে ঘাবড়ে গিয়ে প্রোগ্রাম বন্ধ করে দিল।

```
price = 120
print(prise * 2)
```

**তোমার কাজ:** প্রোগ্রামটা চালাও। error-এর প্রতিটা অংশ আলাদা করে পড়ো: কোন লাইনে সমস্যা, error-এর নাম কী, আর বার্তাটার মানে কী। তারপর ঠিক করো। শেষে লেখো, Python নিজে কেন ভুলটা ঠিক করে নিতে পারল না।

**Constraint:** ঠিক করার সময় শুধু একটা শব্দ বদলাতে পারবে।

## Task 4 – মাঝারি: সেকেন্ড থেকে ঘড়ি

**পরিস্থিতি:** একটা ম্যারাথন দৌড়ের ফল ঘোষণা হচ্ছে। যন্ত্র দৌড়বিদের সময় শুধু মোট সেকেন্ডে দেয়, যেমন 7325। কিন্তু দর্শকদের পর্দায় সেটা ঘণ্টা:মিনিট:সেকেন্ড আকারে দেখাতে হবে, যেমন 02:02:05।

**তোমার কাজ:** মোট সেকেন্ড নিয়ে ঘণ্টা, মিনিট আর সেকেন্ডে ভেঙে ওপরের আকারে দেখাও। সব অংশ সবসময় দুই অঙ্কের হতে হবে।

**Given Input:**

```
7325
```

**Expected Output:**

```
02:02:05
```

**Constraint:** কোনো loop বা বাইরের library ব্যবহার করা যাবে না। আর ভাগ করার জন্য `/` ব্যবহার করা যাবে না।

## Task 5 – ছোট: ০.১ + ০.২ আর ০.৩

**পরিস্থিতি:** একটা ছোট ক্যাফেতে বিল হিসাব করা হয়। এক কাপ চা ০.১ ডলার আর এক কাপ কফি ০.২ ডলার। ক্যাশিয়ার দেখল, দুটোর যোগফল ০.৩-এর সমান কি না যাচাই করালে কম্পিউটার বলছে "না"। অথচ হাতে হিসাব করলে সমান।

**তোমার কাজ:** এই তুলনাটা চালাও আর দেখো কী আসে। তারপর খুঁজে বের করো কম্পিউটারে এটা কেন ঘটে। শেষে এমন একটা উপায় বের করো যাতে এই দুটো সংখ্যাকে "যথেষ্ট কাছাকাছি, তাই সমান" ধরা যায়।

**Constraint:** তোমার উপায়টা কেন কাজ করে, সেটা এক-দুই বাক্যে লিখতে হবে।

## Task 6 – মাঝারি: পাসওয়ার্ড যাচাই

**পরিস্থিতি:** একটা ছোট অ্যাপে নতুন ব্যবহারকারী নাম আর পাসওয়ার্ড দেয়। পাসওয়ার্ড তখনই গ্রহণযোগ্য হবে যখন তিন শর্তই মিলবে: দৈর্ঘ্য কমপক্ষে ৮, কোনো ফাঁকা জায়গা (space) নেই, আর নামের সমান নয়।

**তোমার কাজ:** নাম আর পাসওয়ার্ড নাও। প্রতিটা শর্তের ফল আলাদা লাইনে `True` বা `False` দিয়ে দেখাও, তারপর শেষ লাইনে তিনটা মিলিয়ে একটা চূড়ান্ত ফল দেখাও।

**Given Input:**

```
rafi
rafi 1234
```

**Expected Output:**

```
True
False
True
False
```

**Constraint:** `if` ব্যবহার করা যাবে না। শেষ ফল একটাই বুলিয়ান রাশিমালা থেকে আসতে হবে।

## Task 7 – ছোট: নামের প্রথম অক্ষর বড় করো

**পরিস্থিতি:** একটা অনলাইন ফর্মে মানুষ নাম লেখে ছোট হাতের অক্ষরে, যেমন "rahim ahmed"। ডাটাবেসে রাখার আগে প্রতিটা শব্দের প্রথম অক্ষর বড় হাতের করতে হবে। কিন্তু মূল লেখাটা যেন অক্ষত থাকে, কারণ লগ রাখার জন্য সেটাও লাগে।

**তোমার কাজ:** নামটা নিয়ে সুন্দর করে সাজানো আকারে আর মূল আকারে, দুটোই দেখাও। প্রোগ্রামটা শেষে এটাও যাচাই করবে যে মূল string আসলেই বদলায়নি।

**Given Input:**

```
rahim ahmed
```

**Constraint:** `title()` আর `capitalize()` ব্যবহার করা যাবে না। slicing আর string জোড়া লাগিয়ে করতে হবে।

## Task 8 – মাঝারি: ফোন নম্বর পরিষ্কার করো

## Task 9 – ছোট: Truthy আর Falsy অনুমান

**পরিস্থিতি:** একটা ফর্মে "খালি নয়" কি না যাচাই করতে গিয়ে এক ডেভেলপার ধরে নিয়েছিল `"0"` আর `0` একই আচরণ করবে। ফর্ম চালু হওয়ার পর বহু ব্যবহারকারীর তথ্য হারিয়ে গেল।

**তোমার কাজ:** এই আটটা মান নাও: `0`, `0.0`, `""`, `" "`, `"0"`, `"False"`, `None`, `-1`। **চালানোর আগে** প্রতিটার জন্য লেখো `bool()` কী ফেরত দেবে। তারপর চালিয়ে মেলাও। যেখানে ভুল হয়েছে সেখানে কেন ভুল ভেবেছিলে, লেখো।

**Constraint:** অনুমান লিখে না রেখে চালানো যাবে না।

## Task 10 – মাঝারি: ভুল বিল

**পরিস্থিতি:** রাকিব একটা দোকানের বিল হিসাবের সূত্র লিখেছে। তার উদ্দেশ্য ছিল: দাম থেকে ছাড় বাদ দিয়ে, সেই দামকে পরিমাণ দিয়ে গুণ করা। কিন্তু প্রতিবার ভুল টাকা আসছে।

```
price = 200
qty = 3
discount = 10
total = price + qty * price - discount / 100 * price
```

**তোমার কাজ:** প্রথমে কাগজে হাতে হিসাব করো `total`-এর মান কত হবে (precedence মেনে)। তারপর চালিয়ে মেলাও। এরপর রাকিবের আসল উদ্দেশ্য অনুযায়ী ঠিক সূত্র লেখো আর তার ফল দেখাও।

**Constraint:** ঠিক সূত্রটা একটাই লাইনে হতে হবে।

## Task 11 – বড়: দোকানের পূর্ণ বিল

**পরিস্থিতি:** একটা মুদি দোকানে ক্রেতা একটা জিনিস কেনে। দোকানি একক দাম, পরিমাণ আর ছাড়ের শতাংশ দেয়। ক্রেতাকে একটা পরিষ্কার বিল দেখাতে হবে, যেখানে সব টাকা সবসময় দুই দশমিক ঘর পর্যন্ত দেখাবে।

**তোমার কাজ:** তিনটা মান নিয়ে মোট দাম, ছাড়ের টাকা আর চূড়ান্ত দাম দেখাও। সব মান `input()` থেকে আসবে।

**Given Input:**

```
249.50
3
10
```

**Expected Output:**

```
Subtotal: 748.50
Discount: 74.85
Total: 673.65
```

**Constraint:** variable-এর নাম এক অক্ষরের হতে পারবে না। `round()` ব্যবহার না করে output সাজাতে হবে।

## Task 12 – মাঝারি: মান নেই, নাকি মান শূন্য?

**পরিস্থিতি:** একটা পরীক্ষায় করিম অনুপস্থিত ছিল, তাই তার নম্বর নেই। সালমা উপস্থিত ছিল কিন্তু প্রতিটা প্রশ্নে ভুল করেছে, তাই সে পেয়েছে ০। স্কুলের সিস্টেম দুজনকে একই ধরা শুরু করায় করিমকে "ফেল" আর সালমার ফলাফল "অনুপস্থিত" দেখানো হচ্ছে।

**তোমার কাজ:** দুজনের নম্বর দুটো variable-এ রাখো এবং প্রতিটার `type` ও `bool()`-এর ফল দেখাও। এরপর `result = print("hello")` লিখে `result`-এ কী আছে দেখো, আর বের করো `print()` আসলে কিছু ফেরত দেয় কি না। শেষে নিজের ভাষায় লেখো `None` আর `0` কেন এক নয়।

**Constraint:** ব্যাখ্যা শুধু এই স্কুলের উদাহরণ ধরে দিতে হবে।

## Task 13 – ছোট: ক্রম বদলালেই ফল বদলে যায়

**পরিস্থিতি:** একটা দৌড় প্রতিযোগিতায় গড় গতি বের করা হয় দূরত্বকে সময় দিয়ে ভাগ করে। কিন্তু কেউ যদি সময় ০ দেয়, প্রোগ্রাম বন্ধ হয়ে যায়। একজন বলল, "শর্তের ক্রম বদলালেই এটা আটকানো যায়।"

**তোমার কাজ:** `time = 0` ধরো। একটা শর্ত লেখো যা প্রথমে "time শূন্য নয়" দেখে, তারপর `distance / time > 5` দেখে। একবার এই ক্রমে চালাও, আরেকবার ক্রম উল্টে। কী পার্থক্য হলো তা লেখো, আর কেন হলো, ব্যাখ্যা করো।

**Constraint:** `if` ব্যবহার করা যাবে না। শুধু `print()`-এর ভেতরে রাশিমালা রেখে করতে হবে।

## Task 14 – বড়: কাগজে trace

**পরিস্থিতি:** তুমি এক নতুন টিমে ঢুকেছ। সিনিয়র তোমাকে একটা কোড দিয়ে বলল, "চালানোর আগে বলো কোথায় কী মান থাকবে।"

```
a = 7
b = 2
c = a // b
d = a % b
a = a + c
b = b ** d
e = (a > b) and (c == 3)
print(a, b, c, d, e)
```

**তোমার কাজ:** **কাগজে** একটা trace table বানাও: প্রতিটা লাইনের পর `a`, `b`, `c`, `d`, `e`-এর মান কী। সেটা টাইপ করে আমাকে পাঠাও। তারপর কোডটা চালিয়ে মেলাও। যেখানে মেলেনি, সেখানে কী ভুল ভেবেছিলে লেখো।

**Constraint:** টেবিল না বানিয়ে কোড চালানো যাবে না।

## Task 15 – মাঝারি: দশমিক থেকে পূর্ণ সংখ্যা

**পরিস্থিতি:** একটা বাসের টিকিট কাউন্টারে যাত্রী-সংখ্যা হিসাব করা হয় মোট টাকা আর ভাড়া দিয়ে। হিসাবে `3.99` সংখ্যক টিকিট এল। কাউন্টারের কর্মী জানতে চায়, কতগুলো **পূর্ণ** টিকিট বিক্রি করা যাবে।

**তোমার কাজ:** `"3.99"` নামের একটা string থেকে শুরু করো। `int("3.99")` চালিয়ে কী হয় দেখো। তারপর `int(float("3.99"))` আর `round(float("3.99"))` চালাও। তিনটার ফল পাশাপাশি দেখাও, আর লেখো "শুধু পূর্ণ টিকিট" এই শর্তে কোনটা সঠিক এবং কেন।

**Constraint:** উত্তরে দুটো ভিন্ন casting-এর পার্থক্য স্পষ্ট করে লিখতে হবে।

## Task 16 – বড়: Python ফাইলটা কীভাবে চালায়?

**পরিস্থিতি:** একজন নতুন প্রোগ্রামার দুই রকম ভুলের মুখোমুখি হয়েছে। একটা ফাইলে ভুল থাকার পরও প্রথম তিন লাইনের output এসেছে। আরেকটা ফাইলে ভুল থাকায় কোনো output-ই আসেনি। সে ভাবছে Python ফাইল কীভাবে পড়ে।

ফাইল ক:

```
print("লাইন ১")
print("লাইন ২")
print("লাইন ৩")
print(naam)
```

ফাইল খ:

```
print("লাইন ১")
print("লাইন ২")
print("লাইন ৩")
print("লাইন ৪"
```

**তোমার কাজ:** চালানোর **আগে** লেখো প্রতিটা ফাইলে কোন কোন লাইনের output আসবে বলে মনে করো। তারপর দুটোই চালাও। দুই ফাইলের আচরণ কেন আলাদা, নিজের ভাষায় ব্যাখ্যা করো। শেষে বলো, এ থেকে "Python কীভাবে ফাইল চালায়" সম্পর্কে কী বোঝা গেল।

**Constraint:** ব্যাখ্যায় `SyntaxError` আর `NameError` দুটো শব্দই থাকতে হবে।
