## Task 1: কোচিংয়ের মাসিক খরচ

**পরিস্থিতি:** আরিফ ক্লাস ইলেভেনে পড়ে। এই মাসে সে হাতখরচ পেয়েছে 2500 টাকা। মাসে 12 দিন কোচিংয়ে যায়। প্রতিদিন রিকশায় যেতে 30 টাকা আর ফিরতে 30 টাকা লাগে। কোচিংয়ের পর বাইরে দুপুরের খাবার খায়, প্রতিদিন 80 টাকা। মাস শেষে সে জানতে চায় মোট কত খরচ হলো, হাতখরচ থেকে কত বাকি আছে, আর কোচিংয়ের দিনগুলোতে প্রতিদিনের গড় খরচ কত।

**তোমার কাজ:** আরিফের এই তিনটা প্রশ্নের উত্তর বের করে দেখাও। কোচিংয়ের দিন, ভাড়া বা খাবারের দাম বদলালে যেন প্রোগ্রামটা সহজে বদলানো যায়।

**Input**
```
Pocket money 2500 
coaching days 12
Rickshaw per trip 30 
lunch per day 80
```

**Output**
```
Total spent: 1680 | Remaining: 820
Average per day: 140
```

**শর্ত:** গড় খরচ `140.0` নয়, `140` হিসেবে দেখাতে হবে।

## Task 2: ক্লাস টেস্টের রেজাল্ট

**পরিস্থিতি:** তুমি স্কুলের এক শিক্ষকের জন্য ছোট একটা টুল বানাচ্ছো। শিক্ষক প্রতিটা ছাত্রের নাম আর তিন বিষয়ের (বাংলা, ইংরেজি, গণিত) নম্বর কীবোর্ড থেকে দেবেন। প্রোগ্রাম ওই ছাত্রের মোট নম্বর, গড় নম্বর আর পাস করেছে কি না তা জানাবে। গড় 40 বা তার বেশি হলে ছাত্র পাস।

**তোমার কাজ:** নাম আর তিন নম্বর আলাদা আলাদা ইনপুট হিসেবে নিয়ে ফলাফল এক লাইনে দেখাও। পাস করেছে কি না সেটা `True` বা `False` হিসেবে আসবে।

**Input**
```
Nusrat
72 65 91
```

**Output**
```
Nusrat | Total: 228 | Average: 76.0 | Passed: True
```

**শর্ত:** পুরো প্রোগ্রামে `print` মাত্র একবার ব্যবহার করা যাবে।

## Task 4: ভাঙা কোড ঠিক করো

**পরিস্থিতি:** Rahim ভাই একটা প্রোগ্রাম লিখেছে। প্রোগ্রামটা নাম আর বয়স নিয়ে বলবে পরের বছর তার বয়স কত হবে। কিন্তু চালালেই ভুল দেখাচ্ছে।

```python
name = "rahim"
name[0] = "R"
age = input("Tomar boyosh koto? ")
next_year = age + 1
print("Hello " + name + ", next year age: " + next_year)
```

**তোমার কাজ:** কোডটা চালাও, কোথায় কী ভুল সেটা নিজে খুঁজে বের করো আর ঠিক করো। কয়টা ভুল আছে, প্রতিটা ভুলের জন্য error message পড়ে নিজের ভাষায় লিখ line by line জে কেন হয়েছে।

**Input**
```
16
```

**Output**
```
Hello Rahim, next year age: 17
```

**শর্ত:** প্রথম লাইনের `"rahim"` বদলানো যাবে না, তবু আউটপুটে বড় হাতের `Rahim` আসতে হবে।

## Task 5: স্কুলের ছাত্রের ইমেইল আইডি

**পরিস্থিতি:** একটা স্কুলে প্রতি বছর শতশত নতুন ছাত্র ভর্তি হয়। অফিসের কর্মী ফর্ম দেখে হাতে হাতে প্রত্যেকের স্কুল-ইমেইল বানায়, আর প্রতিবার কেউ না কেউ ভুল করে। কেউ বড় হাতের অক্ষর দেয়, কেউ আগে-পিছে ফাঁকা জায়গা রেখে দেয়, কেউ নামের মাঝে বিন্দু ভুলে যায়। সবার ইমেইল একই নিয়মে বানানোর জন্য একটা প্রোগ্রাম দরকার। নিয়মটা এরকম: প্রথম নাম, শেষ নাম আর রোল নম্বর বিন্দু দিয়ে জুড়ে, সব ছোট হাতের অক্ষরে লিখে, শেষে `@school.edu` বসবে।

**তোমার কাজ:** প্রথম নাম, শেষ নাম আর রোল নম্বর, এই তিনটা input নাও। ফর্মে যেভাবে লেখা থাকুক, ইউজারনেম আর ইমেইল ঠিক নিয়মে বানাও। এরপর ইউজারনেমে কয়টা অক্ষর আছে সেটাও দেখাও। সবশেষে ছাত্র ফর্মে নিজের প্রথম নাম হুবহু যেভাবে লিখেছিল, সেটা আবার দেখাও। আর শেষ লাইনটা (ফর্মে লেখা নাম) কেমন দেখাবে, সেটা তুমি নিজে দেখে বলবে।

**Input**
```
  Rafi 
AHMED
21
```

**Output**
```
ইমেইল: rafi.ahmed.21@school.edu
ইউজারনেম: rafi.ahmed.21
ইউজারনেমের দৈর্ঘ্য: 13
```

**শর্ত:** `@school.edu` পুরো কোডে একবারই লেখা যাবে।

## Task 7: সিএনজির ভাড়া

10

## Task 10: ছোট একটা পরীক্ষা

**পরিস্থিতি:** তোমার ভাই বলছে, "variable মানে একটা বাক্স, ভেতরে মান রাখা হয়।" তুমি কথাটা পুরোপুরি বিশ্বাস করছো না। Python ভেতরে প্রতিটা মানের জন্য একটা পরিচয়-নম্বর রাখে, সেটা দেখেই তুমি প্রমাণ বের করতে চাও। তিনটা ঘটনা পরীক্ষা করতে চাও। প্রথমত, একটা সংখ্যা variable-এ রেখে পরে একই নামে অন্য সংখ্যা দিলে কী হয়। দ্বিতীয়ত, একটা variable থেকে আরেকটা variable বানালে কী হয়। তৃতীয়ত, একই দুটো ঘটনা একটা লেখা (string) দিয়ে করলে কী হয়।

**তোমার কাজ:** এই তিনটা পরীক্ষা চালাও আর প্রতিটা ধাপে মানের পরিচয়-নম্বর দেখাও। শেষে নিজের ভাষায় লিখে জানাও, তোমার ভাইয়ের "বাক্স" কথাটা কতটা ঠিক, আর কতটা ঠিক নয়।

**Input**
```
কোনো ইনপুট নেই
```

**Output**
```
x = 10 -> id: <একটা সংখ্যা>
x = 20 -> id: <একটা সংখ্যা>
```

**শর্ত:** প্রোগ্রাম চালানোর আগে খাতায় লিখে রাখো কোন কোন ধাপে পরিচয়-নম্বর মিলবে বলে তোমার ধারণা, তারপর চালিয়ে মিলিয়ে দেখো।

## Task 11: কেন কাজ করছে না?

**পরিস্থিতি:** এক শিক্ষার্থী দুটো পরীক্ষার (গণিত আর পদার্থবিজ্ঞান) নম্বরের গড় বের করতে চায়। সে কোড লিখেছে, কিন্তু গড় অদ্ভুত বড় আসছে, বাস্তবে এত গড় হওয়া সম্ভবই না।

```python
math = 80
physics = 65
average = math + physics / 2
print("Average:", average)
```

**তোমার কাজ:** কোডটা কেন কাজ করছে না, বের করো এবং ঠিক করো। আমি কোনো hint দেব না।

**Input**
```
80 
65
```

**Output**
```
Average: 72.5
```

**শর্ত:** ঠিক করার পর কোডে `80` আর `65` শুধু একবার করেই থাকবে, দ্বিতীয়বার কোথাও লেখা যাবে না।

## Task 12: BMI হিসাব

**পরিস্থিতি:** তুমি একটা জিমের জন্য ছোট প্রোগ্রাম বানাচ্ছো। সদস্যরা ওজন কিলোগ্রামে আর উচ্চতা সেন্টিমিটারে বলে। BMI বের করার সূত্র হলো ওজন (কেজি) ÷ (উচ্চতা মিটারে)²। অর্থাৎ উচ্চতাকে মিটারে নিয়ে তার বর্গ দিয়ে ওজনকে ভাগ করতে হবে।

**তোমার কাজ:** ওজন আর উচ্চতা ইনপুট নিয়ে BMI দেখাও।

**Input**
```
72
150
```

**Output**
```
BMI: 32.0
```

**শর্ত:** উচ্চতা সেন্টিমিটারে ইনপুট নেবে, কিন্তু মিটারে রূপান্তর প্রোগ্রামকেই করতে হবে। `1.5` তুমি হাতে লিখে বসাতে পারবে না।

## Task 13: অনলাইন অর্ডারের স্ট্যাটাস কার্ড

**পরিস্থিতি:** একটা অনলাইন শপে কেউ অর্ডার করলে অ্যাপে একটা স্ট্যাটাস কার্ড দেখায়। কার্ডে থাকে অর্ডার নম্বর, গ্রাহকের নাম, পণ্যের নাম, ডেলিভারি হয়েছে কি না, আর কোন রাইডার পণ্য নিয়ে আসছে। অর্ডার দেওয়ার মুহূর্তে রাইডার ঠিক থাকে না, কয়েক মিনিট পরে একজন রাইডার নিযুক্ত হয়। তখন কার্ডটা আপডেট হয়। এই প্রোগ্রামটা সেই কার্ডের কাজ করবে।

**তোমার কাজ:** গ্রাহকের নাম আর পণ্যের নাম input নাও। অর্ডার নম্বর `00472` ধরে নাও। অর্ডার দেওয়ার মুহূর্তের কার্ডটা দেখাও। প্রতিটা তথ্যের পাশে তার type-ও থাকবে। এরপর রাইডার নিযুক্ত হলো। তার নাম `Kamal।` কার্ডটা আবার দেখাও।

**Input**
```
Nusrat
Headphone
```

**Output**
```
অর্ডারের মুহূর্তের কার্ডে অর্ডার নম্বর, নাম, পণ্য, ডেলিভারি আর রাইডার, এই পাঁচ লাইন থাকবে। রাইডারের পরে Kamal বসানোর পর কার্ডে কোন লাইনে কী বদলাল আর কোন type বদলাল, সেটা তুমি নিজে দেখে বলবে। সেটা এখানে লিখে দিইনি।
```

**শর্ত:** অর্ডার নম্বরের শুরুর দুটো `0` কার্ডে দেখাতে হবে।

## Task 14: ফর্মের তথ্য যাচাই

**পরিস্থিতি:** একটা অনলাইন ফর্ম অ্যাপ তিনটা তথ্য নেয়: নাম, বয়স আর উচ্চতা (মিটারে)। কিন্তু অ্যাপের ডেভেলপার সন্দেহ করছে, ভেতরে মানগুলো আসলে ঠিক ধরনের (type-এর) হয়ে সংরক্ষিত হচ্ছে কি না। সে আরও চায়, বয়স দেখে প্রোগ্রাম নিজেই বলে দিক ব্যক্তি প্রাপ্তবয়স্ক (১৮ বা তার বেশি) কি না, `True` বা `False` আকারে।

**তোমার কাজ:** তিনটা তথ্য ইনপুট নিয়ে চারটা মান (নাম, বয়স, উচ্চতা, প্রাপ্তবয়স্ক কি না) এক লাইনে দেখাও, আর তার নিচের লাইনে এই চারটা মানের type দেখাও। প্রতিটা মান যে type-এর হওয়া উচিত ঠিক সেই type-এই থাকতে হবে।

**Input**
```
Rafi
17 
1.68
```

**Output**
```
Rafi 17 1.68 False
<class 'str'> <class 'int'> <class 'float'> <class 'bool'>
```

**শর্ত:** কাজ করার সময় তুমি নিজে প্রতিটা মানের type আগে-পরে দেখে নিশ্চিত হবে, কিন্তু চূড়ান্ত প্রোগ্রামে শুধু উপরের দুই লাইনই আসবে, বাড়তি debug `print` সব মুছে ফেলতে হবে।

## Task 15: এটিএম থেকে টাকা তোলা

**পরিস্থিতি:** একটা ছোট এলাকার এটিএম মেশিনে শুধু 500 টাকা আর 100 টাকার নোট আছে। কেউ কোনো পরিমাণ টাকা চাইলে মেশিন আগে যত বেশি সম্ভব 500 টাকার নোট দেয়, তারপর বাকিটা 100 টাকার নোটে। এরপরও যদি কিছু টাকা থেকে যায় যেটা 100-এর নোটে দেওয়া যায় না, সেটা মেশিন দিতে পারে না।

**তোমার কাজ:** টাকার পরিমাণ ইনপুট নিয়ে কয়টা 500-র নোট, কয়টা 100-র নোট আর কত টাকা দেওয়া সম্ভব নয়, সেটা দেখাও।

**Input**
```
3750
```

**Output**
```
500-notes: 7 | 100-notes: 2
Cannot dispense: 50
```

**শর্ত:** `500` আর `100` কোডে একবার করেই লেখা থাকবে, বারবার নয়।

## Task 16: বাজারের হিসাব

**পরিস্থিতি:** একজন দোকানি কোনো ফাইল থেকে পণ্যের দাম পড়ে, কিন্তু সেই দাম প্রোগ্রামে সবসময় লেখা (text) আকারে আসে। সে চালের দাম প্রতি কেজি 60 টাকা ধরে 5 কেজির দাম বের করতে চায়। কোড চালালে কোনো error আসে না, কিন্তু উত্তরটা দেখে সে হতবাক।

```python
item = "rice"
kg = 5
rate = "60"
cost = rate * kg
print(item + " cost: " + cost)
```

**তোমার কাজ:** কোডটা চালিয়ে দেখো কী আসছে, কেন আসছে বের করো, তারপর ঠিক করো। কয়টা ভুল আছে বা কোথায় আছে, আমি কিছুই বলব না।

**Input**
```
60 
5
```

**Output**
```
rice cost: 300
```

**শর্ত:** `rate = "60"` লাইনটা যেমন আছে তেমনই থাকবে, বদলানো যাবে না।

## Task 17: বেতনের স্লিপ

**পরিস্থিতি:** একটা ছোট কোম্পানির হিসাব বিভাগ প্রতি মাসে কর্মীদের বেতনের স্লিপ বানায়। কর্মীর মূল বেতন (basic) জানা থাকলে বাকিটা এভাবে হিসাব হয়। বাড়ি ভাড়া ভাতা মূল বেতনের 50%, চিকিৎসা ভাতা মূল বেতনের 10%। মূল বেতন আর এই দুই ভাতা যোগ করলে মোট বেতন (gross)। এই মোট বেতনের 5% কর কাটা হয়, কর বাদ দিলে হাতে পাওয়া বেতন (net)। কোম্পানির নিয়ম হলো, টাকার সব অঙ্ক পূর্ণসংখ্যায় দেখাতে হবে, কোনো ভগ্নাংশ নয়।

**তোমার কাজ:** মূল বেতন ইনপুট নিয়ে মোট বেতন, কর আর হাতে পাওয়া বেতন দেখাও।

**Input**
```
30000
```

**Output**
```
Gross: 48000 | Tax: 2400
Net salary: 45600
```

**শর্ত:** 50, 10 আর 5 এই তিনটা শতকরা হার কোডে একবার করেই লেখা থাকবে, যেন কোম্পানি হার বদলালে একটা জায়গাতেই বদলানো যায়।
