**পরিস্থিতি:**


## Task 8 (মাঝারি) — বাস ভাড়া

**পরিস্থিতি:**

## Task 13 (বড়) — সংখ্যা অনুমানের খেলা (ঠিক ৪টা সমস্যা)

**পরিস্থিতি:**
একটা ছোট খেলায় কম্পিউটারের মাথায় একটা গোপন সংখ্যা (১ থেকে ১০০-র মধ্যে) থাকে। খেলোয়াড় ৫ বার পর্যন্ত অনুমান করতে পারে। প্রতিবার ভুল হলে সংকেত পায়: সংখ্যাটা আরও বড় না ছোট। সঠিক হলে "সঠিক!" দেখায় আর খেলা থেমে যায়। শেষে "খেলা শেষ" দেখায়। নাদিম কোড লিখেছে, কিন্তু কোডে ঠিক ৪টা সমস্যা আছে।

```python
secret = 37
tries = 0
while tries < 5
    guess = input("অনুমান করো: ")
    tries = tries + 1
    if guess == secret:
        print("সঠিক!")
    elif guess < secret:
        print("আরও ছোট সংখ্যা দাও")
    else:
        print("আরও বড় সংখ্যা দাও")
print("খেলা শেষ")
```

**তোমার কাজ:**
