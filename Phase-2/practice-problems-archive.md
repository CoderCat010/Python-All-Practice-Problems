## Task 1 — লাইব্রেরির জরিমানা

**পরিস্থিতি:** কলেজ লাইব্রেরিতে বই ফেরত দিতে দেরি হলে জরিমানা হয়। প্রথম ৩ দিন দেরি হলে কোনো জরিমানা নেই। এরপর প্রতিদিন ৫ টাকা করে জরিমানা। কিন্তু জরিমানা কখনো ১০০ টাকার বেশি হবে না। লাইব্রেরিয়ান প্রতিবার হাতে হিসাব করে, আর অনেক সময় ভুল করে।

**তোমার কাজ:** কত দিন দেরি হয়েছে সেটা input নাও। জরিমানা বের করে দেখাও।

**Input:**
```
10
```

**Output:**
```
জরিমানা: 35 টাকা
```

**শর্ত:** ৩, ৫ আর ১০০ পুরো কোডে একবারের বেশি লেখা যাবে না। ২ দিন আর ৪০ দিন দিয়েও চালিয়ে দেখো।

## Task 6 — পরীক্ষার অনুমতি, পুরো ক্লাসের (ঠিক ৩টা সমস্যা)

**পরিস্থিতি:** একটা কলেজে পরীক্ষায় বসার নিয়ম: উপস্থিতি ৭৫% বা বেশি হলে বসতে পারবে। ৬০% থেকে ৭৪% হলে মেডিকেল সার্টিফিকেট থাকলে জরিমানাসহ বসতে পারবে। তার নিচে বা সার্টিফিকেট না থাকলে বসতে পারবে না। অফিস পুরো ক্লাসের সবার তথ্য একসাথে দিয়ে ফল দেখতে চায়। কোডটা লেখা হয়েছে, কিন্তু ঠিকমতো চলছে না। এতে ঠিক ৩টা সমস্যা আছে।

```python
students = int(input("কতজন ছাত্র: "))
regular = 0
fined = 0
count = 1
while count <= students:
    attendance = int(input("উপস্থিতি %: "))
    has_medical = input("মেডিকেল সার্টিফিকেট (yes/no): ")
    if attendance >= 75:
        print("ছাত্র", count, ": পরীক্ষায় বসতে পারবে")
        regular = regular + 1
    elif attendance >= 60 or has_medical = "yes":
        print("ছাত্র", count, ": জরিমানাসহ বসতে পারবে")
        fined = fined + 1
    else:
        print("ছাত্র", count, ": বসতে পারবে না")
print("সাধারণ:", regular, "| জরিমানাসহ:", fined)
```

**তোমার কাজ:** ৩টা সমস্যা খুঁজে ঠিক করো।

**Given Input:**
```
4
80
yes
68
yes
68
no
50
yes
```

**Expected Output:**
```
ছাত্র 1 : পরীক্ষায় বসতে পারবে
ছাত্র 2 : জরিমানাসহ বসতে পারবে
ছাত্র 3 : বসতে পারবে না
ছাত্র 4 : বসতে পারবে না
সাধারণ: 1 | জরিমানাসহ: 1
```

**Constraint:** ঠিক করার পর প্রতিটা বদলানো লাইনের পাশে এক লাইনের comment-এ লিখে রাখবে কেন ঠিক করলে।

## Task 7 — ট্রাফিক পুলিশের দিনের রিপোর্ট

85

## Task 10 — ডেটা ব্যবহারের হিসাব

**পরিস্থিতি:** মিনহাজের মোবাইল প্যাকেজে সপ্তাহে ১০০০ MB ডেটা পাওয়া যায়। প্রতি সপ্তাহের শেষে সে বুঝতে পারে না ডেটা কোন দিন শেষ হলো আর কোন দিন সবচেয়ে বেশি খরচ হয়েছে। সে প্রতিদিন কত MB খরচ করেছে সেটা একে একে বলবে, আর প্রোগ্রাম হিসাব দেবে।

**তোমার কাজ:** ৭ দিনের ডেটা ব্যবহার (MB) একে একে input নাও। শেষে এই চারটা জিনিস দেখাও: (১) কোন দিন প্রথমবার সীমা পার হলো (পার না হলে সেটাও বলো), (২) মোট ব্যবহার, (৩) কোন দিন সবচেয়ে বেশি আর কত, (৪) প্রতিদিনের গড়, দশমিকের পরে ২ ঘর।

**Given Input:**
```
120
340
90
410
220
150
80
```

**Expected Output:**
```
সীমা (1000 MB) পার হয়েছে দিন 5-এ
মোট ব্যবহার: 1410 MB
সবচেয়ে বেশি: দিন 4 (410 MB)
গড় প্রতিদিন: 201.43 MB
```

**Constraint:** ১০০০ আর ৭ পুরো কোডে একবারই লেখা যাবে। সীমা কখনো পার না হলে প্রোগ্রাম কী দেখাবে, সেটাও পরীক্ষা করো।

## Task 11 — চায়ের দোকানের অর্ডার

**পরিস্থিতি:** একটা ছোট চায়ের দোকানে ক্রেতারা একে একে অর্ডার বলেন। দোকানদার মনে রাখতে পারেন না কয়টা জিনিস হলো আর মোট কত। মেনু: চা ১৫ টাকা, কফি ৪০ টাকা, সিঙ্গারা ১২ টাকা। ক্রেতা মেনুর বাইরের কিছু বললে "এই আইটেম নেই" বলে আবার জিজ্ঞেস করা হয়। ক্রেতা "শেষ" বললে অর্ডার শেষ।

**তোমার কাজ:** এই অর্ডার নেওয়ার প্রোগ্রামটা বানাও। অর্ডার শেষে মোট আইটেম আর মোট বিল দেখাও।

কফি
পরোটা
চা
শেষ

**Expected Output:**

মোট বিল: 70 টাকা

**Constraint:** প্রতিটা দাম পুরো কোডে একবারই লেখা যাবে। ব্যবহারকারী আগে-পিছে ফাঁকা দিলেও (যেমন `"  চা "`) যেন প্রোগ্রাম ঠিক চলে।

## Task 12 — সংখ্যা অনুমানের খেলা (ঠিক ৪টা সমস্যা)

**পরিস্থিতি:** একটা ছোট খেলায় কম্পিউটারের মাথায় একটা গোপন সংখ্যা (১ থেকে ১০০-র মধ্যে) থাকে। খেলোয়াড় ৫ বার পর্যন্ত অনুমান করতে পারে। প্রতিবার ভুল হলে সংকেত পায়: সংখ্যাটা আরও বড় না ছোট। সঠিক হলে "সঠিক!" দেখায় আর খেলা থেমে যায়। শেষে "খেলা শেষ" দেখায়। নাদিম কোড লিখেছে, কিন্তু কোডে ঠিক ৪টা সমস্যা আছে।

```python
secret = 37
tries = 0
while tries < 5
    guess = input("অনুমান করো: ")
    tries = tries + 1
    if guess == secret:
        print("সঠিক!")
    elif guess < secret:
        print("আরও ছোট সংখ্যা দাও")
    else:
        print("আরও বড় সংখ্যা দাও")
print("খেলা শেষ")
```

**তোমার কাজ:** ৪টা সমস্যা খুঁজে বের করো আর ঠিক করো।

**Given Input:**
```
50
20
37
```

**Expected Output:**
```
আরও ছোট সংখ্যা দাও
আরও বড় সংখ্যা দাও
সঠিক!
খেলা শেষ
```

## Task 13 — কুরিয়ার চার্জ

**পরিস্থিতি:** একটা কুরিয়ার সার্ভিস ঢাকার ভেতরে প্রথম ১ কেজির জন্য ৬০ টাকা নেয়, তারপর প্রতি বাড়তি কেজির জন্য ১৫ টাকা। ঢাকার বাইরে প্রথম ১ কেজি ১১০ টাকা, বাড়তি প্রতি কেজি ২৫ টাকা। কেজির ভগ্নাংশ থাকলে পুরো এক কেজি ধরা হয় (যেমন ২৩০০ গ্রাম মানে ৩ কেজি ধরে চার্জ)। সর্বোচ্চ ৩০ কেজি পাঠানো যায়।

**তোমার কাজ:** পার্সেলের ওজন (গ্রামে) আর গন্তব্য (inside বা outside) input নাও। কত কেজি ধরে চার্জ হচ্ছে আর মোট কত টাকা, দেখাও। ওজন ০ বা ঋণাত্মক হলে "অবৈধ ওজন", ৩০ কেজির বেশি হলে "ওজন বেশি, পাঠানো যাবে না" দেখাবে।

**Given Input:** (উদাহরণ ১, ২ ও ৩, মাঝে ফাঁকা লাইন)
```
2300
outside

2300
inside

1001
outside
```

**Expected Output:** (উদাহরণ ১, ২ ও ৩ — একই ক্রমে)
```
চার্জযোগ্য ওজন: 3 কেজি | চার্জ: 160 টাকা
চার্জযোগ্য ওজন: 3 কেজি | চার্জ: 90 টাকা
চার্জযোগ্য ওজন: 2 কেজি | চার্জ: 135 টাকা
```

**Constraint:** কোনো import ব্যবহার করা যাবে না। ঠিক ১০০০, ১০০১ আর ৩০০০০ গ্রাম দিয়েও নিজে চালিয়ে দেখো।
